# 家康の憂鬱：設計メモ

このゲームの仕組みを、なぜそうしているかとあわせて残しておくメモ。
仕組みを足したり直したりするときは、まずここを読んでから考える。

## ゲームの芯

- プレイヤーは、霊体となって江戸城に降りた家康（権現様）。将軍を支えて、徳川幕府をできるだけ長く続ける
- 1年に1つ出来事が起き、それへの裁きと、政務の間での備え（教育・制度・人事・財務）を繰り返す
- 倒幕されたら終わり。何年続いたかと、得た栄誉が記録になる

## ヒット作から学んだこと（2026年10月の調査）

似たジャンルのヒット作について、攻略サイトや解説記事を読み、共通する面白さを取り出した。
まねをするのではなく、「なぜ面白いのか」の原理だけを借りている。

| 学んだこと | 参考にした作品 | このゲームでの形 |
|---|---|---|
| ゲームは「面白い決断の連続」。どの選択にも得と損がある | Sid Meier（Civilization） | 出来事の選択肢は、どれも何かを得て何かを失う。費用や成否の見込みは見せる |
| 強すぎても弱すぎても破滅する、均衡の遊び | Reigns | 威光・民心・朝廷が0で危機。80を超えると「慢心」で自然に下がる |
| 短い周期と、数字が伸びる手応えで「もう1回」を生む | カイロソフト（ゲーム発展国++） | 1年ごとの決算報告で、収支・純資産・状態の増減をまとめて見せる |
| 組み合わせの発見（ジャンル×内容、社員のドリームチーム） | ゲーム発展国++ | 制度の「組み合わせの妙」。そろうまで名前を伏せ、手がかりだけ見せる |
| 適材適所。家臣を役目に就けて育てる | 信長の野望 | 6つの役職と家臣の能力。役目の中で腕が上がり、老いて辞める |
| 人物の性格に反する決断はストレスになる | Crusader Kings III | 将軍の「気苦労」。好みに合わない裁きでたまり、体を壊す |
| 跡継ぎの教育と継承が、国ではなく「家」の物語を生む | Crusader Kings | 若君の教育、隠居、御三家、家系図 |
| 緊張と緩和の波。厳しい出来事のあとに一息つかせる | RimWorld（語り手AI） | 厳しい出来事が続くと良い出来事が来やすく、穏やかな年が続くと試練が来やすい |
| 選択の結果が、のちに返ってくる | Reigns、Frostpunk | 借金・改易・普請・大奥・開国が、数年後に続きの出来事として返ってくる |
| 失敗しても次につながる（メタ進行） | ローグライト全般 | 栄誉は周回をまたいで残り、集めると新しい「遺訓」（最初の布石）が選べる |
| 現実の題材は、知らなくても遊べるように | Sid Meier | 史実の知識はなくても遊べる。ガイドとチュートリアルで説明する |

## 数字の決まりごと（調整するときの目安）

- お金の単位は万両。年貢は石高×民心×将軍と勘定奉行の腕。物価は年におよそ1.2%ずつ上がるが、年貢は石高で決まるので追いつかない
  → 投資（新田開発・交易）をしないと、だいたい100年ほどで赤字になる
- 悪い出来事の痛手は、年が進むほど大きくなる（150年で2.0倍）
- 何も考えずに選ぶ自動プレイで、だいたい150〜200年続くくらいを狙っている。史実の約265年を超えるには工夫が要る
- 栄誉が集まって遺訓が解禁されると、300年を超えることもある（倒れても次の幕府は少し強くなる、というねらい）
- 調整用の数値は `game.js` の `CONFIG` にまとめてある

## ファイルの役割

- `cards.js`：物語・出来事・制度・組み合わせ・栄誉・チュートリアル・ガイド。文章と数値はここだけ直せばよい
- `game.js`：1年の流れ、帳簿、組織、家系図、画面の描画
- `art.js`：イラスト。SVGをコードで描いている（画像ファイルや外部サービスは使わない）
- `style.css`：ゲーム専用の見た目
