# 家康の憂鬱：設計メモ

このゲームの仕組みを、なぜそうしているかとあわせて残しておくメモ。
仕組みを足したり直したりするときは、まずここを読んでから考える。

## ゲームの芯

- プレイヤーは、霊体となって江戸城に降りた家康（権現様）。将軍を支えて、徳川幕府をできるだけ長く続ける
- 1年に1つ出来事が起き、それへの裁きと、政務の間での備え（教育・制度・人事・財務）を繰り返す
- 倒幕されたら終わり。何年続いたかと、得た栄誉が記録になる

## ヒット作から学んだこと（2026年10月の調査）

似たジャンルのヒット作について、攻略サイトや解説記事を読み、共通する面白さを取り出した。
まねをするのではなく、「なぜ面白いのか」の原理だけを借りている。

## 数字の決まりごと（調整するときの目安）

- お金の単位は万両。年貢は石高×民心×将軍と勘定奉行の腕×米価。物価は年におよそ1.2%ずつ上がる。米価も上がるが、物価の上がりの2割ぶんだけ（`NENGU_PRICE`。下の「普請」を入れたときに3割から下げた）
  → 投資（新田開発・交易）をしないと、時代が下るほど苦しくなる
- 借入が上限を超えても、幕府は倒れない（所有者の希望。カイロソフトでも金が尽きて終わることはない）。
  年の暮れに商人へ借金の棒引き（棄捐令）を命じ、借入を上限の6割まで減らす。かわりに威光−4・民心−3（年が進むほど重い）、出来事で増やした交易の上がりが半分になる（`KIEN_*`）
- 悪い出来事の痛手は、年が進むほど大きくなる（150年で2.0倍）
- 自動プレイは `node scripts/ieyasu-selfplay.mjs` で試せる（使い方はファイルの先頭）。仕組みや数値を直したら、前後で比べる
  - 2026年10月、将軍の格と縁組を入れる前の計測（300回）：
    でたらめに選ぶ（random）と平均124年・中央値123年。ひととおり考えて選ぶ（basic）と平均180年・中央値157年で、1割が史実を超える。
    倒れる理由は、どちらも財政（借入が上限を超える）がいちばん多い
  - 将軍の格と家臣の去就を入れたあと（同じ条件）：random 平均117年・中央値116年、basic 平均181年・中央値159年。
    将軍を育てるかどうかで差が少し広がった。random では家臣が100年あたり約11人去り、倒れる理由に威光・民心が増えた
  - 縁組と世継ぎのガチャを入れたあと（同じ条件）：random 平均115年・中央値113年、basic 平均176年・中央値161年。
    はじめは正室・側室・姫の婚礼の費えが重すぎて basic が平均152年まで縮んだので、費えを下げて元の水準に戻した
  - 御三家を代々続く家にしたあと（同じ条件）：random 平均118年・中央値117年、basic 平均178年前後。
    basic は御三卿をいつも立てる遊び方で、天領を30万石割く形だと平均168年まで縮んだ（立てなければ189年）。
    重すぎて選ぶ理由のない制度だったので、天領は割かずに賄料（毎年4万両）を払う形にした
  - 異国船を入れたあと（同じ条件）：random 平均120年・中央値119年、basic 平均181年・中央値164年。
    random は白船が9割来て86%勝つ（赤船は2割来て8%勝つ。黒船までは届かない）。
    basic は白船99%・赤船90%・黒船74%勝ち、17%が黒船を退けて結末を迎える（平均 開府195年）。
    はじめは難しさを白10・赤12・黒14にしたが、basic が黒船に94%勝ったので、11・15・19に上げた
  - 2026年10月の品質評価で、出来事でいつもいちばんお金になる選択肢を選ぶ遊び方（money）を足して測ったら、
    平均509年・中央値550年で92%が史実を超え、93%が黒船を退けた（同じ条件で basic は181年）。
    威光・民心・朝廷は放っておいても満ち、出来事で増やした交易の上がりが永久に伸び続けるので、お金だけ見れば勝ててしまっていた。
    下の「ゲージとお金のつながり」を入れたあと（200回）：random 平均94年、basic 平均173年・中央値171年、money 平均254年・中央値255年（史実超え32%）。
    お金を意識して遊ぶほうが長く持つのは正しい姿なので、money が basic より長いこと自体は残している。random は120年から94年に縮んだ
  - ゴールを黒船にしたあと（各200回）。ここからの物差しは「黒船まで届いたか・退けたか」：
    basic は91%が黒船まで届き、届いた回の38%が退ける（結末まで行けたのは35%）。money は99%が届き、44%が退ける。
    random は威光・民心が尽きて平均95年で倒れる（白船が来るのは35%）。
    はじめは財政で倒れないようにしただけだったが、basic でも開府160年ごろから棒引きを毎年のように繰り返し、威光が尽きて平均190年で倒れた。
    年貢が物価にまったく追いつかないので、後半は何をしても赤字になる作りだった。米価の連動を0.4にすると basic は最後まで金が余り（開府200年で約5,000万両）、
    0.2だと黒船まで届くのが59%だったので、0.3にした（開府200年で約2,800万両。棒引きは4割の回で、ほとんど黒船のあと）。
    黒船まで届く回が増えたので、黒船の難しさを19→25、赤船を15→19に上げた（黒船19のままだと、basic が92%勝った）
- 栄誉が集まって遺訓が解禁されると、300年を超えることもある（倒れても次の幕府は少し強くなる、というねらい）
- 調整用の数値は `engine.js` の `CONFIG` にまとめてある

## 将軍の格と家臣の去就（2026年10月に入れた）

「将軍が強くないと良い家臣が集まらない」を仕組みにしたもの。カイロソフトの「社員が会社の格に見合うかで集まる」に近い。

- 将軍の格 ＝ 政務・武威・人徳の合計（若君・跡継ぎの候補も同じ数え方で見せる）。上の帯の右下に出す
- 毎年の登用の候補の数は格で決まる：24未満は1人、24以上で2人、40以上で3人、52以上で4人（`CANDIDATE_STEPS`）
- 候補の得意な能力に、(格−30)÷6 を上乗せする。腕は格÷2 を超えない（格に見合わない者は、はじめから来ない）
- 格40以上なら、名のある人物（大岡忠相など。`cards.js` の `renowned`）がまれに候補に現れる。
  見込みは年 (格−38)×0.5%（格50で6%）。その年だけで、1回の幕府で1人1度まで。
  実在の人物名を使うことは、所有者が了承している（2026年10月）
- 家臣は「腕（いちばん高い能力）×2」の格を将軍に求める。届かないと年の暮れに不満を漏らし、次の暮れにも届かなければ去る
  （いきなり去らせず、1年の猶予で手を打てるようにしている）
- 加増すると、俸禄がもとの額の5割ずつ増えるかわりに、求める格が6ずつ下がる。弱い将軍の代は金で人をつなぎとめる
- 特技（`cards.js` の `skills`、10種類）：将軍・若君にまれにつき、特定の役職や能力に効く。働くのは、いまの将軍の特技だけ。
  若君は父や母（正室）の特技を3割の見込みで受け継ぎ、そうでなくても8%の見込みで新しい特技がつく。保科正之は「名伯楽」を持って始まる

## 縁組と世継ぎ（2026年10月に入れた）

「能力の高い姫と世継ぎを作ると将軍家の血は強くなるが、良い家臣を雇う金に困る」を仕組みにしたもの。
数値は `cards.js` の `brides`・`stars` と、`engine.js` の `CONFIG`。

- 正室のいない将軍（16〜50歳）には、年のはじめに縁談が来る。公家の姫・大名の姫・家臣の娘から1人ずつ候補が出る
  - 公家の姫：教養（政務・人徳）が高く、朝廷+8。婚礼の費え20万両、大奥の費え 年+3万両
  - 大名の姫：武威が高く丈夫。威光+5と持参金20万両。大奥の費え 年+2万両。4年ほどのちに「外戚の口出し」が来る
  - 家臣の娘：能力は控えめだが丈夫で安い（婚礼5万両、大奥 年+1万両）
  - 見送ると3年後にまた来る。将軍が代わると正室と側室は大奥を退き、新しい将軍は縁組からやり直す
- 子が生まれる見込みは、正室で年25%、側室1人ごとに+15%（側室は1人 年2万両、3人まで）。生まれた子の55%が若君、45%が姫
  - 大奥のもとの費えは年6万両にした（以前は10万両。正室と側室のぶんを上に乗せるため）
- 若君の能力 ＝（父と母の能力の平均）×0.75 ＋ −1〜2 ＋ 素質の上乗せ。母が強いほど強い若君が生まれる（血筋の育成。下の「血を育てる」で0.45から上げた）
- 素質（★1〜5）はくじ。★1 凡庸20%・★2 並40%・★3 良25%・★4 秀才11%・★5 名君の器4%。
  ★が高いほど生まれたときの能力が高く、15歳まで育ちやすい。★5は必ず特技を持つ。決算報告で、誕生を別の枠で見せる
- 側室の子は、母の能力がそのつど運しだい（くじを引く回数が増えるかわりに、中身はばらつく）
- 若君は3人まで。枠が埋まったら他家へ養子に出して空けられる（支度金10万両・威光+2）。御三家へ出す形は、のちの「御三家」の仕組みで足す
- 姫（3人まで）は13歳から、大名家（威光+4）や公家（朝廷+5）へ嫁がせられる。迎える屋敷は受ける側が建てるので、幕府の費えは軽い（8〜10万両）
- 栄誉を2つ足した：「名君の器」（★5の若君が生まれた）と「名士を招く」（名のある人物を召し抱えた）

## 御三家と御三卿（2026年10月に入れた）

「まんべんなく子孫を残したほうが得」を仕組みにしたもの。史実でも、吉宗の子が立てた一橋家から家斉が、
家斉の子が継いだ紀州家から家茂が将軍になっている（子を分家に出すと、血が回り回って本家に戻ってくる）。
数値は `cards.js` の `branches`・`kyo` と、`engine.js` の `CONFIG`。

- 御三家は、はじめから必ずある（以前は「最後の布石」で選んだときだけだった）。布石の「御三家を固める」は、三家の血筋が強い状態（格36。ふつうは格27）で始まる効果に変えた
- 各家は「血筋」（政務・武威・人徳。跡継ぎの候補の能力の目安）と、当主の名前・代を持つ。当主は12年たつと、年5%の見込みで代替わりする（名前は史実の歴代当主）
- 血筋は毎年1%ずつ平凡（各8・格24）に近づく。70年ほどで差が半分になる。はじめ2%にしたら、布石で固めた血筋が最初の代替わりの危機に間に合わなかったので下げた
- 本家の若君を養子に出すと、その家の血筋が、若君が大人になったときの見込み（15歳まで自然に伸びるぶんを足す）まで上がる。能力ごとに高いほうが残るので、下がることはない。支度金15万両。若君の特技はその家に残る
- 代替わりでは、本家の若君のほかに、各分家から1人ずつ候補が出る（血筋±2に、家風の得意を上乗せ）。若君をさしおいて迎えると威光−5（吉宗の先例の「救済」）、若君がいなければ威光−3。
  将軍を出した家は、血筋が平凡との中間まで薄まり、当主も代わる
- 家風（分家から迎えた将軍のあいだだけ働く）：紀伊＝倹約（経費−5%）、尾張＝華美（民心+1/年・交易+15%・大奥の費え+30%）、水戸＝学問と尊王（実績+1・朝廷+1/年。朝廷が70を超えると威光−1/年）
- 三家がそろって格30以上で、差が6以内なら、威光+1/年。一家がほかの二家の平均より格8以上高いと、出来事「御三家の横やり」が来やすくなる（手本は宗春と吉宗の対立）。
  その出来事で、突出した家の血筋を下げたり、ほかの二家を引き立てたりできる
- 御三卿は制度で立てる（実績6・40万両・賄料が毎年4万両）。血筋はそのときの将軍の能力から始まり、家風はなく、口を出さない（釣り合いや横やりの勘定に入らない）
- 跡目争いは、分家がひとつもないとき（ふつうは起きない）だけに残した
- 栄誉「三家鼎立」（御三家の血筋が、そろって格40以上）を足した。格36だと、布石で固めた始まりの年に取れてしまうので40にした

## 異国船（2026年10月に入れた）

「組織として強くした幕府の腕を試す」ボス戦。白船・赤船に史実のモデルはなく、黒船の前の練習試合として置いた。
数値は `cards.js` の `ships`・`shipRounds` と、`engine.js` の `CONFIG.SHIP_*`。

- 白船 → 赤船 → 黒船の順に来る。来る年は1700年・1777年・1853年ごろ（それぞれ前後2年のどこか。周回のはじめに決める）。
  黒船は史実どおりの年で、1周の大きなゴール。以前は「幕府が長く続くほど来やすい」ランダムだったが、ゴールを黒船にしたので、数年の幅のランダムにした（所有者の希望）
- 予兆から来航まで3〜5年。上の帯に「来航まで、あと◯年」、政務の間に「異国船への備え」（勝負ごとの力と見込み）を出す
- 来航の年は、その年の出来事のかわりに勝負になる。勝負は役職ごと（海防＝大目付、交渉＝老中、軍資金＝勘定奉行、朝廷＝京都所司代、人心＝町奉行、祈祷＝寺社奉行）
  - 白船は海防・交渉の2回で1勝、赤船は4回で3勝、黒船は6回で4勝すれば退けられる。勝ち負けが決まった時点で終わる
  - 力 ＝ 役職の腕（特技の上乗せこみ）＋ 将軍の能力÷4（＋長崎奉行があれば海防・交渉に2）。見込み ＝ 0.5 ＋（力−難しさ）×8%（10〜95%）
  - 難しさは白船11・赤船19・黒船27（普請で台場・大船を造れるようにしたとき、25から上げた）。勝負ごとに軍資金（白20・赤30・黒40万両×物価）を投じると、力が3上がる
- 白船・赤船に負けると威光が大きく下がり金も失う（長崎奉行があれば半分）。黒船に負ければ倒幕。
  黒船を退けると結末の場面になり、そのまま続けることもできる（もう異国船は来ない。開国したので「異国渡りの流行」が来る）
- 以前の出来事カード「異国の黒い船」は、このボス戦に置き換えて消した
- 栄誉「白船退散」「赤船退散」「黒船退散」を足した。絵は白船・赤船・予兆（水平線の船影と見張り）を足した

## ゲージとお金のつながり（2026年10月に入れた）

品質評価（自動プレイで、お金だけ見て選ぶと平均509年続いた）を受けて、「ゲージを損ねると、数年かけてお金で返ってくる」形にした。
数値は `engine.js` の `CONFIG`（GAUGE_PULL など）。

- 慢心：以前は80を超えると毎年−2だった。いまは50を超えたぶんの2割が毎年戻る（`GAUGE_PULL`）。よい将軍と役職がそろっても100に張りつかない
- 放っておくと、威光と民心は毎年1ずつ下がる（`DRIFT_SHIFT`。のちに「能力の働きを見えるように」で1.4にした）。朝廷はもともと将軍の能力では伸びないので外した（入れたら朝廷で倒れる幕府が急に増えた）
- 威光：50より高ければ「大名の献上・手伝い普請」が入り、低ければ「大名を見張る費え」がかかる（1あたり0.4万両×物価）
- 民心：年貢の取れ高への効きを2倍にした（民心50でもとの取れ高、0で7割、100で13割ほど）
- 朝廷：50を下回るほど、朝廷・寺社への費えがかさむ（1下回るごとに5%）
- 交易：出来事で増やした運上金・交易は、流行り廃りで毎年6%細る（`TRADE_DECAY`）。はじめの5万両と、制度（長崎奉行）や組み合わせの妙で得たぶんは細らない。
  money が強すぎたいちばんの原因は、交易の上がりが永久に、しかも時代とともに伸び続けることだった
- 試したこと：ゲージ側（慢心・献上・年貢）だけを強めても money はほとんど縮まなかった（509→491年）。
  money の選ぶ選択肢の半分は、もともとゲージを1つも下げないためで、交易の細りを入れて初めて縮んだ
- 華美を好む選択肢がほかの性格より1割以上少なかった（21個）ので、7つの選択肢を華美に付け替えた（いま28個）

## 能力の働きを見えるように（2026年10月に入れた）

所有者から「各パラメーターが何に役立つかわからない」と言われて入れた。説明が散らばっていたことと、
1上げても何も変わらないことが多い（5ごとの段差）ことの両方が原因だったので、説明と仕組みの両方を直した。

- 段差をなくした：将軍の武威・人徳と、役職の腕による威光・民心・朝廷の毎年の増減を、端数つきで計算する。
  端数は `state.carry` にたまり、1になった年に効く（`withCarry`）。武威・人徳は10を基準に1につき毎年0.2、役職は腕10を基準に4につき1（寺社奉行は8につき1）
  - 以前は「武威÷5の切り捨て−2」だった。ならすと0.4ぶん低かったので、そのぶん `DRIFT_SHIFT` を−1から−1.4にして釣り合いを保った
  - 実績も、政務12以上・老中14以上で+1の段差だったのを、8を超えた6につき1（最大2）のなめらかな形にした（`abilityJisseki`）
  - 成否の判定で役職が助けるぶんも、切り捨てをやめた（腕が9を超えた3につき能力1ぶん）。異国船の勝負の「将軍の能力÷4」も切り捨てをやめ、力は小数1けたで出す
- 人徳：成否の判定に使う選択肢が1つしかなかった（政務22・武威13）。人をまとめる・納得させる場面の5つを政務から人徳に付け替え、2つに人徳の判定を足して7つにした
- 体質：若君の「健康」（1〜20）と将軍の「健康」（0〜100）が同じ名前の別物だったので、若君のほうを「体質」と呼び替えた（中身の名前は `kenko` のまま）。
  体質は将軍になっても残り、歳による健康の衰えにかかる（体質10で1倍、20で半分、4以下で1.3倍。`constitutionWear`）。体質を持たない古い保存データとはじめの将軍は10として扱う
- お金：千両（0.1万両）まで刻む。俸禄が能力の合計÷12を整数に丸めていたため、どの家臣もほぼ同じ額だった。
  文の中では「12万5千両」（`formatRyo`）、表の中では「12.5」と書く。決算の項目も千両まで計算する
- 画面：宣下の表紙と組織の画面の将軍の札に「能力の働き（いまの効き目）」を、組織の画面の役職ごとに「いまの効き目」を出す。ガイドに「能力の働き」の節を足した
- 自動プレイ（300回）：basic は平均357→353年・中央値252→252年、黒船に勝つ割合47→49%。random は平均100→99年。釣り合いはほぼ変わらない

## 積み重なる歴史：諸家の覚え（2026年10月に入れた）

「次の計画」の段階7。友人のレビューの「プレイヤーごとに違う歴史」を、大名・商人・朝廷の「覚え」（恩と恨み）として入れた。
威光・民心・朝廷のゲージは毎年50に戻ろうとするので、昔の裁きは数年で消えてしまう。覚えはゆっくりとしか薄れないので、一代の仕打ちが次の代まで尾を引く。
文章（新しい出来事12枚）は Claude の下書き。数値は `engine.js` の `CONFIG`（OBOE_*）と、`cards.js` の各選択肢の `oboe`。

- 覚えは家ごとに −10〜+10（プラスが恩、マイナスが恨み）。毎年2%ずつ0に近づく（35年ほどで半分）
- たまり方：出来事の選択肢に `oboe` を書いた（57の選択肢。改易・お手伝い普請は大名の恨み、借金の棒引きは商人の恨み、朝廷への抗議は朝廷の恨み、など）。
  ほかに、正室を大名の姫・公家の姫から迎える（+1）、姫を大名家・公家へ嫁がせる（+0.5）、若君を大名家へ養子に出す（+0.5）、棄捐令（商人−4）。
  姫の縁組ははじめ+1にしたら、basic が毎回すべての姫を大名家へ嫁がせるので、大名の恩がいつも満ちてしまった。0.5に下げた
- 覚えが動くたびに、わけ（「無断の城普請で「改易する」と裁いた」など）を60件まで残す。出来事の文中の `{urami:daimyo}` `{on:daimyo}` は、
  残っているわけのうち、動いた量がいちばん大きいものになる（「かつて無断の城普請で「改易する」と裁いたことを、大名たちは忘れていない」）
- 効き目
  - 出来事の出やすさ：`grudge`（恨まれているほど出る。無断の城普請・外様の縁組・大名連合の噂・朝廷の官位・朝廷の不満・政を朝廷に返せ・贋金）、
    `favor`（恩を売っているほど出る。加賀からの献上・大坂の豪商・米相場の会所・商人の仲間・琉球からの使節）。1深まるごとに1/4ずつ出やすい
  - 覚えが深い（±5）と出る出来事（`deep`）：外様の連判状・諸大名の申し出・商人の貸し渋り・豪商の御用金・密勅の噂・朝廷の勅使。恩の出来事は、恩を使えば金やゲージになるが、覚えは浅くなる
  - 危機の出方：倒幕の危機の年は、覚えが±3に届いている家の出来事（`crisis`）が、ほかの出来事より先に出る。恩なら助けに来て（諸大名の後押し・豪商の肩入れ・朝廷の取りなし。恩を使って尽きかけたゲージを戻せる）、
    恨みなら敵に回る（外様の挙兵・商人の見切り・討幕の勅）
  - 異国船：海防に大名の、軍資金に商人の、朝廷に朝廷の覚えの1/4が力に足される（`shipRounds` の `oboe`）
  - 借りられる上限：商人の覚え1につき2.5%増減する
- 画面：選択肢の下に「大名の覚え●」などを出す（上げ下げは伏せる）。政務の間と記録のメニューに、いまの覚えとわけの一覧、幕府の年表に1行。ガイドに「諸家の覚え（恩と恨み）」の節を足した
- 自動プレイ（各150回）：遊び方で歴史が変わる。basic（好みで選び、姫は大名家へ嫁がせる）は1852年の暮れに大名の恩が平均+4（+5以上が30%）で、
  諸大名の申し出が1回あたり1.5回。money（お金だけで選ぶ）は朝廷の恨みが平均−4（−5以下が27%）で、密勅の噂が1.1回、危機の年には討幕の勅や外様の挙兵が来る。
  黒船に勝つ割合は basic 50→47%、money 47→36%。お金だけを見て諸家を踏みつけにすると、黒船の前で響く形になった。
  random は危機1回あたり、商人の見切り0.31・諸大名の後押し0.10・外様の挙兵0.07回。続いた年数（平均100年）は変わらない

## ファイルの役割

- `cards.js`：物語・出来事・制度・組み合わせ・栄誉・チュートリアル・ガイド。文章と数値はここだけ直せばよい
- `engine.js`：ルール。1年の流れ、帳簿、組織、家系図。画面（document）には触れないので、自動プレイでもそのまま動く。
  状態は `state` ひとつで、操作は状態を変えるだけ。外から使えるものは、ファイルの最後の `IEYASU_ENGINE` に並べてある
- `game.js`：画面の描画と、ボタンを押したときの受け渡し。ルールの操作を呼んだあと、保存して描き直す（`commit`）。
  確かめの問い（「養子に出しますか？」など）、音、チュートリアルもここ
- `art.js`：イラスト。SVGをコードで描いている（画像ファイルや外部サービスは使わない）
- `style.css`：ゲーム専用の見た目
- `audio.js`：音。Web Audio API でその場で合成する（音のファイルや外部サービスは使わない）。`sound-test.html` は聞き比べ用の非掲載ページ

## 組織として強くする相談（2026年10月。4つとも入れた）

カイロソフトのような育成・成長の手応えを、将軍ひとりを強くするのではなく、史実の幕府のように「組織として強くする」ことで出したい、という相談で出た案。
格 → 縁組 → 御三家 → 船の順に1つずつ入れて、そのつど遊んで確かめた（仕組みを一度に足すと、1年に出来事1つというテンポが重くなるため）。
決まりは上の各節にある。ここには、案を出したときの考え（なぜそうするか）を残しておく。

### 芯にしたい悩み

- 将軍家の血筋（家）と、家臣（組織）が、同じ財布を取り合う
- 将軍が強くないと良い家臣が集まらない。けれど血筋を強くしようとすると、良い家臣を雇うお金に困る

### 1. 将軍の格で、集まる人材が決まる

（2026年10月に入れた。決まりは上の「将軍の格と家臣の去就」を参照。格は相談の結果、威光を混ぜずに能力の合計だけにした）

- 「幕府の格」を1つの数字で見せる。将軍の能力と威光から決まる
- 格が高いと、登用の候補が良くなり、人数も増え、名のある人物がたまに来る
- 格が下がると、腕の立つ家臣ほど去っていく
- 優秀な家臣ほど俸禄が高い（いまもそうなっている）
- 弱い将軍の代は家臣に支えてもらうしかないのに、その家臣が離れていく。強い将軍の代は、人材をそろえる好機になる

### 2. 縁組と、世継ぎのガチャ

（2026年10月に入れた。決まりは上の「縁組と世継ぎ」を参照。若君の枠を空けるために、他家へ養子に出す操作も足した）

- 正室を選ぶ
  - 公家の姫：朝廷との関係が良くなる。持参金は少ない
  - 大名の姫：威光が上がる。ただし外戚が口を出してくる
  - 家臣の娘：安上がり。そのぶん能力も控えめ
- 側室を増やすと子が生まれやすくなる（ガチャを引く回数が増える）。そのかわり大奥の費えが毎年かさむ
  （史実でも大奥は財政の重荷だった。家斉には子が50人以上いた）
- 子の能力は両親から受け継ぎ、振れ幅がある。生まれたときに「名君の器」「凡庸」などの格付けを★で見せる
- 外れたときの救済を用意する。教育で伸ばせる（いまもある）。御三家から養子を迎えられる（吉宗の先例）
- 振れ幅は最初は控えめにして、遊びながら広げる

### 3. 御三家を「代々続く家」にする

（2026年10月に入れた。決まりは上の「御三家と御三卿」を参照。御三卿は、天領を割く形が重すぎたので賄料の形にした）

史実では、15代の将軍のあいだにあった14回の代替わりのうち、6回は父から子へまっすぐ継げていない。

| 代 | 将軍 | どこから来たか |
|---|---|---|
| 5代 | 綱吉 | 4代家綱の弟（館林藩主） |
| 6代 | 家宣 | 綱吉の甥（甲府藩主） |
| 8代 | 吉宗 | 紀州家（御三家） |
| 11代 | 家斉 | 一橋家（御三卿） |
| 14代 | 家茂 | 紀州家（御三家） |
| 15代 | 慶喜 | 水戸家の生まれ。一橋家に養子に入ってから将軍に |

御三家の当主からそのまま将軍になったのは、紀州家の吉宗と家茂の2人だけ。尾張家からは一度も出ていない。
吉宗は息子たちに田安家・一橋家を立てさせ（のちに清水家が加わって御三卿になる）、その一橋家から吉宗のひ孫の家斉が将軍になった。
家斉は多くの子を分家や大名家に出し、紀州家を継いだ子の、その子が家茂になった。
子を分家に出しておくと、血が回り回って本家に戻ってくる。これを「まんべんなく子孫を残したほうが得」という形にする。

- いまの御三家は、本家が絶えたときにその場で候補を作るだけ。これを、当主と血筋の強さを持って代々続く家にし、家系図にも並べる
- 跡継ぎに選ばれなかった若君を、御三家へ養子に出せる（持参金がかかる）。その家の血筋が強くなる。ガチャで余った子にも使い道ができる
- 血は放っておくと、代を重ねるごとに平凡に近づく。強いままにするには、ときどき本家から子を送り込む
- 三家ごとに家風を持たせる
  - 紀伊：倹約（吉宗の改革）
  - 尾張：華美（吉宗の倹約に逆らって名古屋を栄えさせた宗春）
  - 水戸：学問と尊王。朝廷とはうまくいくが、行き過ぎると倒幕の火種になる（史実の水戸学）
  - 借金が膨らんだら紀伊、景気が冷えたら尾張、朝廷とこじれたら水戸、と危機に合う将軍を迎えられる。
    どんな危機が来るかは前もってわからないので、三家とも育てておくことが保険になる
- 一家だけ強すぎると、跡目に横やりを入れたり、政策に逆らったりする。三家が釣り合っていれば、互いに牽制して静か
  （手本は宗春と吉宗の対立や、幕末の跡継ぎ争いでの一橋派と南紀派）
- 最初の2つ（代々続く家・養子に出せる）があれば遊べる。残りは「まんべんなく」に理由を付ける味付け
- 後半の広がりとして、御三卿を制度で作れるようにする。家ごとに天領を10万石割くので年貢は減るが、
  藩も城も持たないので口を出さない、扱いやすい分家になる

### 4. 船のボス戦（白船・赤船・黒船）

（2026年10月に入れた。決まりは上の「異国船」を参照。来る時期は、所有者の希望でランダム＋長く続くほど来やすい形にした）

## 次の計画：延命から「ゴールのある1周」へ（2026年10月の相談）

友人のレビューと、それを受けた相談で決めたこと。上の4つ（格・縁組・御三家・船）がそろったあとの、次の大きな方向。

### なぜ変えるか

- 「史実より長く続くか」を物差しにすると、遊ぶ目的が延命だけになる。終わりはいつも負けで、うまく回り始めると中盤がだれ、何が上達なのかも見えにくい
- 延命を軸にしたヒット作も、生き延びることは「負けないための条件」にとどめ、遊ぶ動機は別のゴールとして置いている
  （RimWorld の脱出、Frostpunk のシナリオの終わり、Crusader Kings の野望、Reigns の目標）
- 所有者の望み：はっきりしたゴールがあり、果たすと対価があり、その対価でより大きなゴールを目指す形。ボリュームはカイロソフト（ゲーム発展国++ は1周およそ5時間）くらいで、数分ごとの小さな区切りがほしい

### 所有者が決めたこと

- 大きなゴールは「黒船を退ける」。史実より何年続いたかは、物差しから外して記録として残す
- 1周はおよそ5時間。1手1年のまま、黒船は史実どおり1853年ごろに来る（開府250年。本編は1637年からなので、約216年ぶんの決断）。1年あたり約70秒の見当
- 異国船の来る時期は、数年の幅のランダムでよい（白船1700年ごろ・赤船1777年ごろ・黒船1853年ごろ、それぞれ±2〜3年の窓を目安にする）
- 時代で章を分けると先が見えてしまうので、章は「将軍1代」にする。いまある時代の掛け合い（`eras`）は、章とは呼ばず、時代の移り変わりを告げる幕間として残す
- 宿願は、2〜3個から選ぶ形にする
- 血筋は「育てる」ゲームにする（いまは遺伝の割合が0.45で、母の能力の差が子にほとんど届かず、教育と★のくじで決まっている）
- 予告のない急死は、ごくまれに残す（あとで調整する）
- 財政で幕府が終わるのは厳しすぎる。カイロソフトでは金が尽きても終わらないので、同じくらいにする
  （2026年10月の自動プレイでは、倒れる理由の99%が財政だった）

### 将軍1代を1章にする

いまの basic で将軍1代は平均16年ほど。1年70秒なら1代は約18分で、1章にちょうどよい。章の長さも数もその回しだいなので、先は読めない。

1. 幕開け：将軍宣下。表紙（第◯代 ◯◯ 御治世・顔・格・性格）を出し、宿願を2〜3個から1つ選ぶ
2. 治世：上の帯に宿願の進み具合を出す。3〜5年ごとに普請の評定が来る
3. 晩年：御不例。健康が一定を切ると、1〜3年の「最後の時間」に入ったことを知らせる。宿願の追い込みと、跡継ぎの仕上げを急ぐ場面
4. 終幕：遺言。2〜3個から1つ選び、次の代に引き継ぐ（例：「倹約を守れ」＝次の代は経費が下がるが、華美な裁きでは気苦労がたまる）。代と代がつながって、その回だけの歴史ができる
5. 御治世の評定：在位中の裁きの癖からあだ名（言行録）をつけ、宿願の達成と点を出す。家系図と年表に残す
6. 跡継ぎ選び（いまのまま）→ 次の章へ

宿願を果たすと「家訓」が1つ増え、代をまたいで残る（例：教育+1、異国船の勝負で力+1）。宿願を積み重ねるほど、黒船に挑む地力が育つ。
