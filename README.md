# HbarCG.github.io

個人で運営する、文章・思考・実験のためのサイト。

## 目的

- 書きたかったエッセイを継続的に公開する
- 日常的に考えたこと、ビジネスアイデア、社会や人間についての考察を文章として残す
- 将来的に小さなWebアプリや実験的なサービスも公開する
- note、Xなどの外部プラットフォームに依存せず、自分で所有・管理する

## 技術構成

意図的にシンプルにしてある。

- 素のHTML / CSS / JavaScript（フレームワーク・ビルドツールなし）
- ホスティング：[GitHub Pages](https://pages.github.com/)
- バージョン管理：Git / GitHub

## フォルダ構成

```
.

├── about/                自己紹介

├── robots.txt             検索エンジン向けの設定
└── sitemap.xml            検索エンジン向けのページ一覧
```

## 新しいエッセイを追加する手順

エッセイのページは、`scripts/essays.mjs` が1つのテンプレートから作る。
HTMLを手で書いたり、既存のページをコピーしたりはしない（フォントや文字の大きさがページごとにずれる原因になる）。

1. 下書きをテキストファイルに書く（置き場所はどこでもよい。公開前の原稿なのでリポジトリの中には置かない）

   ```
   タイトル: 効率を楽しむ、非効率を楽しむ
   フォルダ: two-kinds-of-fun
   日付: 2026-08-31
   説明: 検索結果やSNSに出る1〜2文の要約

   ここから本文。1行が1段落になる。
   ## 見出し
   > 目立たせたい一文
   - 箇条書き
   ---
   ```

   - `フォルダ` はURLになる英語の名前。番号（`008-` など）は自動で付く
   - `日付` を省くと今日、`説明` を省くと本文の書き出しが使われる。`副題: …` も書ける
2. `node scripts/essays.mjs new 下書き.txt` を実行する。ページの作成、一覧（`essays/index.html`）と `sitemap.xml` への追加まで済む

既存のエッセイを直したあとは `node scripts/essays.mjs` を実行する。本文以外の部分（`<head>`・ヘッダー・フッター）をテンプレートどおりに戻し、
一覧と sitemap を揃え、本文の書き方の問題（`style="..."` や段落の中の改行など）を指摘する。
見た目を変えたいときは、ページではなく `css/style.css` の「エッセイ本文ページ」を直す。

ただし、他のプロジェクトから取り入れたコードはそれぞれ元のライセンスに従います（該当するファイルやフォルダにライセンスを明記しています）。
